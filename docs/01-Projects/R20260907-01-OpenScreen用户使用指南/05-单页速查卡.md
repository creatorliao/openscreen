# OpenScreen 单页速查卡

> 一句话：**录屏 → 编辑 → 导出**，全程一个软件，专为产品演示/讲解视频设计。免费开源（MIT），无付费墙。

---

## 1. 完整路径（照着走一遍）

```
启动（HUD）→ 选「窗口/屏幕」→ 共享
     → 开麦克风 + 系统音频（可选：摄像头、光标）
     → 点「录制」→ 3-2-1 倒计时 → 边操作边讲解
     → 暂停/继续、重新开始、取消（按需）
     → 点「停止」→ 自动进编辑器
     → 剪辑/缩放/字幕/背景（见下）
     → 导出 MP4 → 在文件夹中显示
```

**记住**：点「停止」后自动进编辑器，不用手动找文件。
**保存/打开**：`.openscreen` 项目文件，`Ctrl/Cmd+S` 保存、`Ctrl/Cmd+O` 打开。

---

## 2. 录制（重点）

| 项 | 说明 |
|----|------|
| 选源 | 演示建议选**窗口**（成片干净，只录该软件） |
| 系统音频 | 录软件本身声音 |
| 麦克风 | 录讲解声；**录制中不能切换**，开始前确认 |
| 摄像头 | 录时开；成片要不要露脸：编辑器「摄像头布局」决定 |
| 光标 | 默认**可编辑光标**（记轨迹供后期润色）；可切换系统光标 |
| 倒计时 | 点录制后自动 3-2-1 |
| 控制 | 暂停/继续、重新开始、取消、停止（红点）、隐藏（−） |

**平台坑**：macOS 13+ 首次要授权「屏幕录制 + 辅助功能」；Windows 10 18362+；Linux 要 PipeWire（系统音频）。

## 3. 编辑速查（时间线）

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 添加缩放 | `Z` | 放大重点区域 |
| 添加剪辑 | `T` | 标记删除片段（红色区域导出时剪掉） |
| 添加变速 | `S` | 快进/慢放 |
| 添加标注 | `A` | 文本/箭头/图片/模糊 |
| 添加全屏摄像头 | `C` | 摄像头占满整屏 |
| 添加音频 | `M` | 配音/背景乐图层 |
| 录制配音 | `V` | 从播放头录旁白 |
| 删除选中 | `Ctrl/Cmd+D` | 删除 |
| 播放/暂停 | `空格` | — |
| 复制/粘贴属性 | `Ctrl/Cmd+C` / `Ctrl/Cmd+V` | 同类区域套属性 |
| 撤销/重做 | `Ctrl/Cmd+Z` / `Ctrl/Cmd+Shift+Z` | — |
| 循环切换标注 | `Tab` / `Shift+Tab` | — |
| 平移时间线 | `Shift + 滚轮` | — |
| 缩放时间线 | `Ctrl/Cmd + 滚轮` | — |
| 上一帧/下一帧 | `←` / `→` | — |

**编辑器三模式**：媒体（素材库）/ 编辑（时间线）/ 录制（开新录）。

## 4. 省时剪辑（减轻工作量）

| 招 | 怎么做 |
|----|--------|
| **自动缩放**（最省事） | 时间线工具栏「自动缩放」/「根据光标建议缩放」 |
| 录出好缩放素材 | 重点处**停顿、点击**，自动缩放更准 |
| **转录剪辑**（更快） | 转录后：双击改字、退格删词（画面同步剪掉）、点静音标记剪静音 |
| 智能剪切 | 时间线「智能剪切」（用 AI，需转录） |
| 光标润色 | 调大光标 + 点击弹跳 |
| 修剪废段 | `T` 标记，导出自动删 |
| 变速拖沓段 | `S` 快进 |
| 背景美化 | 壁纸/纯色/渐变 + 阴影/圆角/内边距/运动模糊 |

## 5. 字幕与配音

| 需求 | 做法 |
|------|------|
| **自动字幕** | 媒体里转录（本地 Whisper，离线）→ 字幕面板开「显示字幕」 |
| 字幕样式 | 字体/字号/粗体/颜色/背景/位置/行长 |
| 字幕改错 | 转录面板双击改字，字幕自动跟随 |
| 字幕翻译 | 字幕面板「翻译」（需 AI 提供方；不覆盖原文） |
| **配音（现场）** | 录制时**开麦克风**，边操作边讲（最常用） |
| **配音（后期）** | `V` 录配音 / `M` 导入音频，音频轨道调音量/淡入淡出/循环 |

## 6. 导出

| 项 | 选择 |
|----|------|
| 格式 | **MP4**（演示）/ GIF（轻量循环） |
| 分辨率 | 720p / **1080p（默认）** / 源画质（Source） |
| GIF | 帧率、循环、尺寸（中/大/原始） |
| 编码 | GPU 硬件编码（Metal/D3D11/Vulkan），无 GPU 自动 CPU 回退 |
| 收尾 | 完成后「在文件夹中显示」 |

## 8. 演示视频省时套路（总口诀）

```
录前光标保持「可编辑」→ 录时重点处停顿点击
→ 录后：转录 → 转录里删口误/静音 → 修剪废段(T)
→ 套自动缩放 → 调大光标+点击弹跳 → 套背景
→ 开字幕 → 导出 MP4 1080p
```

> 完整教程见同目录 `README.md` 及 `01`～`04` 篇。
