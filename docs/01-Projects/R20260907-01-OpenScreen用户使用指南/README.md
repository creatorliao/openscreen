## 二、一句话认识 OpenScreen

**OpenScreen 是一款免费、开源的桌面「录屏 + 剪辑」一体应用**，专门为做产品演示（product demo）、教学讲解、walkthrough 视频的人设计。

它解决的是这个痛点：你以前录完屏，可能还要把素材丢给剪辑软件去补缩放、美化光标、加背景、加字幕。OpenScreen 把这一整套都内置了——**录完直接进编辑器，动几下鼠标就能导出一段像样的演示视频**，全程免费，没有付费墙、没有高级版、没有用量上限（MIT 协议）。

> 说明：本仓库是原 OpenScreen v1.5.0 归档后的社区延续版本，同名、同 MIT 协议，仍处于活跃开发中——会有粗糙边缘，`.openscreen` 项目格式和 CLI 也可能变动。本教程基于当前源码与界面文案整理。

支持平台：**macOS 13+、Windows 10 (Build 18362+)、Linux**。三端都走原生采集管线（macOS ScreenCaptureKit、Windows 图形捕获、Linux PipeWire），编辑器和导出能力三端一致。

## 三、功能全景（一次看全它到底会什么）

按「录制 → 编辑 → 导出」三段来归类：

### 录制阶段
- 录制**整个屏幕**或**单个应用窗口**（原生采集，画质更好、窗口级采集更干净）
- 录**麦克风声音**和**系统声音**
- 可选**摄像头**，画中画叠加，成片要不要露脸由编辑器里的「摄像头布局」决定
- **可编辑光标**（默认）：录制时记录光标轨迹，后期可换样式、调大小、加效果；也可切换为「系统光标」直接烧进画面
- **倒计时**：点录制后自动倒数 3 秒再开始
- 录制中可**暂停/继续**、**重新开始**、**取消**

### 编辑阶段
- 三段式编辑器：**媒体**（素材库）/ **编辑**（时间线）/ **录制**（开新录）
- **拖拽式时间线**：多个片段排列、调入点/出点，加缩放、剪辑、变速、标注、全屏摄像头、音频轨道
- **自动缩放**：根据你录制时的光标停留，自动建议该放大的位置（减轻剪辑工作量的关键）
- **光标润色**：样式、大小、平滑、运动模糊、点击弹跳
- **摄像头布局**：画中画 / 垂直堆叠 / 双画框，形状、镜像、背景、缩放时自动缩小
- **画面合成**：壁纸 / 纯色 / 渐变 / 自定义背景 + 阴影、圆角、内边距、运动模糊
- **标注**：文本、箭头、图片、模糊（高斯 / 马赛克），带文本动画
- **裁剪**：裁掉画面多余部分、重设宽高比
- **转录**：本地 Whisper 语音识别，像编辑文档一样改字、剪词（剪掉口误/静音）
- **字幕**：从转录实时派生的字幕层，可调样式、可翻译
- **AI 编辑（可选）**：聊天式编辑，自带 API Key，默认关闭
- **项目保存**：存成 `.openscreen` 文件，随时回来接着改

### 导出阶段
- **MP4**（常规视频）或 **GIF**（轻量分享 / 循环）
- 分辨率：**720p / 1080p / 源画质（Source）**，默认 1080p
- GIF 帧率、循环开关、尺寸预设（中 / 大 / 原始）
- GPU 硬件编码（macOS Metal、Windows D3D11、Linux Vulkan），无 GPU 时自动回退 CPU
- 导出后在系统文件管理器里定位文件

### 可选 AI（默认关闭，全部可独立开关）
- **本地 Whisper 转录**：离线、不上传、不联网
- **转录驱动剪辑**：在转录上选词删除，画面同步剪掉
- **字幕派生层**：字幕实时跟随转录，改转录字幕跟着变，可翻译成多语言
- **聊天式 AI 编辑**：描述你要的编辑，代理在时间线上落地（自带 Claude / OpenAI / Gemini / Mistral / OpenRouter / MiniMax / 任意 OpenAI 兼容端点的 Key）

### 命令行（供脚本 / CI / 智能体）
- `openscreen record / sources / export / pack / captions / info`，无界面、NDJSON 输出，详见 `docs/cli.md`

### 多语言
界面支持 **13 种语言**，含简体中文、繁体中文。
