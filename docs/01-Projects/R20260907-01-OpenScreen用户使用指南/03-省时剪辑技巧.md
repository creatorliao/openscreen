# 03 · 省时剪辑技巧（减轻剪辑工作量）

> 这一篇专门回应你的诉求：**「录制完成后，能帮我减轻剪辑工作量」**。
>
> 结论先说：OpenScreen 的一大设计目标就是**让你几乎不用做传统剪辑**。很多「剪辑活」它在你录制时就已经帮你准备好了。

---

## 一、核心思路：把「剪辑」变成「确认」

传统做法：录完 → 打开剪辑软件 → 手动找重点 → 手动加缩放 → 手动美化光标 → 手动加字幕……

OpenScreen 的做法：

1. 录制时**自动记录你的光标活动**（在哪停顿、在哪点击）。
2. 录制后**自动据此建议缩放位置**，你只需一键应用。
3. 光标、背景、字幕这些「美化」都是**面板里点几下**的事，不是逐帧去修。
4. 更进一步，它把语音转成**转录文本**，让你**像编辑文档一样剪视频**——删掉一行字，画面里那几句话就没了。

所以你的剪辑工作量大头，被「自动缩放」「转录剪辑」「一键美化」吃掉了。

---

## 二、自动缩放：最省事的功能

### 2.1 它是什么

你操作软件时，镜头会自动「放大」到你正在点的地方，让观众看清菜单和按钮。这是演示视频的**灵魂**——不用你再手动切镜头。

### 2.2 怎么用

| 用法 | 在哪 | 说明 |
|------|------|------|
| **自动缩放** | 时间线工具栏「自动缩放」按钮 | 根据录制中的光标移动，一键生成一批缩放区域 |
| **根据光标建议缩放** | 时间线工具栏 | 手动触发，让 OpenScreen 根据光标停留点生成缩放建议 |
| **自动对焦** | 时间线工具栏开关 | 开：所有缩放镜头跟随光标；关：每个缩放单独设焦点 |

> 提示语会引导你：如果录制里光标移动数据不够，它会提示「录制内容没有包含足够的光标移动数据」——**也就是说，录的时候在重点处多停一停、点一点，自动缩放效果会更好。**

### 2.3 配套微调

- 单个缩放可调**缩放级别、焦点位置、时长、缓动**，还能加 **3D 旋转**。
- 缩放区域和已有区域重叠时会提示「无可用的自动缩放位置」，手动微调即可。

## 三、转录剪辑：像改 Word 一样剪视频

这是 OpenScreen 里最「省时」的剪辑方式，值得单独说：

1. 在「媒体」模式或「转录」面板，对录制的视频**转录**（本地 Whisper，离线）。
2. 转录面板会显示整段话，**静音也被标记成 `[静音 x 秒]`**。
3. 三种「剪」：
   - 选中一段文字，按 **退格 / Delete** → 画面里对应的片段被剪掉（红色标记）
   - 双击一个词 → 改正转录错字（比如术语识别错了，改字不改画面）
   - 点静音标记 → 一键剪掉这段静音

> 改字、剪词都是**非破坏性**的，`Ctrl/Cmd + Z` 随时撤销。相比传统剪辑「在时间轴上反复找口误/静音的起止」，这一招快一个量级。

---

## 四、光标润色：让画面显得专业

演示视频里，光标是观众的「视线引导」。OpenScreen 可以：

| 能力 | 作用 |
|------|------|
| **显示光标** | 开/关渲染后的光标叠加层 |
| **光标大小** | 调大，让观众一眼看到你在点哪 |
| **光标平滑** | 让光标轨迹顺滑（消除抖动） |
| **光标运动模糊** | 快速移动时带拖影，更自然 |
| **点击弹跳** | 点击时有个弹跳动画，强化「点这里」 |
| **光标样式** | 多种主题样式 |
| **裁剪到画布** | 放大/平移时光标不越出画面 |

> 演示视频建议：**调大光标 + 开启点击弹跳**，观众最容易跟上你的操作。

---

## 五、修剪：把「废段」一键删掉

录完总有废段：找文件、卡壳、接电话……用**剪辑（Trim）**处理：

1. 按 `T`，在时间线上标出一段**红色剪辑区域**。
2. 拖动红色区域边缘，精确覆盖要剪掉的部分。
3. 导出时，红色区域会被自动删掉。

> 配合「转录剪辑」用更省事：大段废话说错 → 转录里删；小段卡壳 → 时间线 `T` 标。

---

## 六、变速：拖沓的地方快进

- 按 `S` 加**变速区域**，把啰嗦/等待的部分快进，重点部分正常速或慢放。
- 适合「演示里有一段冗长的加载/安装过程」，快进掉，观众不困。

---

## 七、标注：边看边提示

- 按 `A` 加**标注**：文本、箭头、图片、模糊。
- 适合在关键步骤上打「注意」「点击这里」等文字，或把敏感信息**模糊**掉（演示视频里遮内部数据/账号很实用）。模糊有**高斯 / 马赛克**两种、矩形/椭圆形状。
- 文本标注还带**动画预设**（淡入淡出 / 上移 / 弹出 / 打字机等）。

---

## 八、背景与合成：让成片有「成品感」

与其花时间调画布，不如直接用内置样式：

- **背景**：壁纸 / 纯色 / 渐变 / 自定义图片
- **画面合成**：阴影、圆角、内边距、运动模糊、宽高比适配
- **摄像头布局**：画中画 / 垂直堆叠 / 双画框（成片要露脸时用）

点几下，原始录屏立刻变成带精致边框的演示视频。

---

## 九、复制 / 粘贴属性：批量套用

给一段缩放调好了「3×、跟光标、缓动」？选中它按 `Ctrl/Cmd + C` 复制属性，再选另一个同类区域按 `Ctrl/Cmd + V` 粘贴——不用一个个重设。

---

## 十、给演示视频的「省时套路」总结

1. **录之前**：光标保持默认「可编辑光标」（要记轨迹）。
2. **录的时候**：在重点操作处**停顿、点击**，给自动缩放留素材。
3. **录之后**：
   - 先转录 → 在转录里删掉口误/静音（最快）；
   - 再时间线 `T` 补剪废段 → 应用**自动缩放**建议；
   - 调大光标 + 点击弹跳 → 套个背景/边框；
   - 开字幕（见 04 篇）。
4. **导出**：MP4 1080p。

这几步下来，一段演示视频从录完到导出，熟练后可能就几分钟。
