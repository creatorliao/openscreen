# 01 · 核心工作流程是什么

> 这是你使用 OpenScreen 必须建立的第一张心智地图。记住一句话就够了：
>
> **录制（录屏） → 编辑（修整/美化） → 导出（成片）**

---

## 一、三阶段总览

```
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│  ① 录制      │ ───▶ │  ② 编辑      │ ───▶ │  ③ 导出      │
│  录下操作过程 │      │  修整、美化、  │      │  输出 MP4 或 │
│  （屏幕/窗口） │      │  加字幕、配音  │      │  GIF 成片    │
└─────────────┘      └─────────────┘      └─────────────┘
```

对做演示/讲解视频的人来说，最典型的应用方式就是：

1. 打开你要讲的那款软件；
2. 用 OpenScreen 录制你的操作过程（边操作边解说）；
3. 录完自动进入编辑器，把多余片段剪掉、把重点处放大、加个边框/字幕；
4. 导出 MP4，发给别人看。

全程不离开 OpenScreen 这一个软件。

---

## 二、阶段一：录制（Record）

**你在做什么**：选好「录什么」，点录制，然后正常操作你的软件。

- 选择录制源：**整个屏幕** 或 **某一个窗口**（窗口录制的好处是成片干净、不录到桌面其他内容）。
- 配置声音：是否录**麦克风**（你的讲解声）、是否录**系统声音**（软件本身的声音）。
- 可选：开**摄像头**，录时在 HUD 上预览；成片要不要露脸，进编辑器后用「摄像头布局」控制。
- 光标：默认**可编辑光标**——录制时记下光标轨迹，后期能换样式、调大小、加点击效果。
- 点「录制」后自动**倒数 3 秒**，给你准备时间。
- 录制中可**暂停/继续**、**重新开始**、**取消**；确定录完了点**停止**（红色按钮）。

**关键点**：点「停止」之后，OpenScreen 会**自动把你带进编辑器**——不需要手动去找文件。

> 录制入口有两个：启动后悬浮的 **HUD 控制条**（主入口），以及编辑器里的「**录制**」模式（配好源后回到 HUD 开录）。两者用的是同一条采集管线。

---

## 三、阶段二：编辑（Edit）

**你在做什么**：把录下来的素材「收拾成能看的演示视频」。

编辑器顶部有三个模式切换：**媒体（Media）/ 编辑（Edit）/ 录制（Rec）**。日常剪辑主要待在「编辑」模式，它由这几部分组成：

- **中间**：预览画面（所见即所得，和导出同一条渲染管线）
- **下方**：时间线（多个片段 + 各类「区域」）
- **右侧**：属性检查器（按你选中的东西动态变化）
- **左侧/侧栏**：转录面板、字幕面板、聊天（AI）面板

最常用的几个动作：

| 想做什么 | 怎么做（概念层） |
|----------|------------------|
| 剪掉不要的片段 | 在时间线上**加剪辑区域**（快捷键 T），导出时这些红色区域会被删掉 |
| 突出重点区域 | **加缩放**（快捷键 Z），或让 OpenScreen **根据光标建议缩放 / 自动缩放** |
| 调整节奏 | **加变速区域**（快捷键 S），把拖沓的部分快进 |
| 加说明文字/箭头/遮挡 | **加标注**（快捷键 A）：文本、箭头、图片、模糊 |
| 露脸小窗 | 在「摄像头布局」面板选画中画 / 垂直堆叠 / 双画框，调形状/镜像 |
| 美化光标 | 在「光标」面板调样式、大小、平滑、运动模糊、点击弹跳 |
| 美化画面 | 在「背景 / 画面合成」面板加壁纸、渐变、阴影、圆角、内边距、运动模糊 |
| 剪口误/静音 | 在「转录」面板像改文档一样：双击改字、退格删词（画面同步剪掉） |
| 加字幕 | 在「字幕」面板开「显示字幕」（字幕来自转录，实时派生） |
| 配音/背景乐 | 时间线加**音频轨道**（M），或直接**录制配音**（V）/导入音频文件 |

**关键点**：编辑随时可以**保存为 `.openscreen` 项目文件**，下次打开接着改，不会丢。所有编辑都是非破坏性的，`Ctrl/Cmd + Z` 随时撤销。

---

## 四、阶段三：导出（Export）

**你在做什么**：把编辑结果渲染成成品文件。

- 选格式：**MP4**（常规视频）或 **GIF**（轻量分享、循环播放）。
- 调参数：分辨率（**720p / 1080p / 源画质**）、GIF 帧率与循环、尺寸预设。
- 点导出，等渲染完成（GPU 硬件编码，无 GPU 时自动回退 CPU），然后**在文件夹中显示**定位成品。

---

## 五、把三段串起来看一次（演示视频视角）

假设你要录一节「如何在 Excel 里做数据透视表」：

1. **录制**：选「Excel 窗口」为源，开麦克风，开系统声音，点录制，边讲边操作。
2. **编辑**：
   - 用自动缩放，让镜头自动跟着你的光标聚焦在关键菜单上；
   - 把开头找文件、结尾发呆的部分剪掉；
   - 给画面加一个干净的背景/边框；
   - 生成转录后开字幕，让没开声音的人也看得懂；
   - 顺手在转录上把说错的那句话删掉。
3. **导出**：MP4、1080p，导出后发给别人。

这一整套下来，你**几乎没有离开过 OpenScreen**，也不需要额外学剪辑软件。

---

## 六、可选：AI 与命令行（进阶）

OpenScreen 还有两条进阶路径，**默认都是关闭的，不影响上面这条主干路**：

- **AI 编辑**：连接一个你信任的大模型提供方（自带 API Key），就可以用自然语言让代理帮你「剪掉静音、收紧停顿、加字幕、给镜头变焦」。
- **命令行（CLI）**：`openscreen record / export / captions …`，让脚本、CI、智能体自动产出演示视频，无界面运行。
