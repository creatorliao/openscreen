# 04 · 字幕与配音教程

> 这一篇回应你的诉求：**「如果能加上字幕或配音，那就更好了」**。
>
> 好消息：**字幕和配音，OpenScreen 都能做**，而且字幕是**本地自动生成**，不用手动逐句敲。

---

## 一、字幕：本地自动识别，一键生成

### 1.1 原理（一句话）

OpenScreen 内置 **Whisper**（本地语音识别引擎，whisper.cpp），它会「听」你录制里的语音，自动把说话内容转成**转录文本**。**全程在你自己电脑上完成，不联网上传音频，离线可用。**

### 1.2 生成字幕的步骤

字幕不是独立生成的一堆文本，而是**从转录实时派生的一层**——先把视频转录出来，字幕就有了：

1. 在「媒体」模式打开你的录制，点**转录**（或在「字幕」面板点「转录视频」）。
   > 首次会**自动下载语音模型**，之后就在本地跑。用 GPU 时更快；CPU 也能跑（会提示约慢 2 倍）。
2. 转录完成后，到「**字幕**」面板，打开「**显示字幕**」。
3. 字幕会出现在预览和时间线上，**导出时烧录进成片**。

想换语言重识别：在素材卡片上「重新生成为」选语言再生成。

### 1.3 字幕样式（让字幕好看）

字幕面板提供完整样式控制：

| 设置 | 作用 |
|------|------|
| 字体 / 字号 / 粗体 / 文字颜色 | 字幕文字外观 |
| 背景 / 背景颜色 / 不透明度 | 字幕底框 |
| 位置 | 顶部/底部锚点，左/中/右对齐，四边距离 |
| 行长 | 每行最少/最多词数（控制换行） |

### 1.4 字幕改错（个别句子改字）

因为字幕是转录的「实时视图」，所以**改转录 = 改字幕**：

- 到「转录」面板，**双击某个词**改正识别错字；
- 字幕会自动跟着变，不用重新生成。

### 1.5 字幕翻译（可选，需 AI 提供方）

- 字幕面板点「**翻译**」，把转录翻译成其他语言（使用你配置的 AI 提供方）。
- 翻译**保存在转录旁边，绝不改原文**——原文和时间轴始终不动，可随时删掉翻译。

## 二、配音：两种方式

### 方式 A：录制时直接录你的讲解（最简单）

录制阶段**打开麦克风**（见 `02` 篇），你边操作边讲解的声音就会直接进成片。这是做演示**最常用**的配音方式——录屏和配音一次完成。

### 方式 B：后期在时间线加「音频」（配音/背景乐）

如果录完了想补配音、或加一段背景音乐，两种入口：

| 方式 | 快捷键/入口 | 说明 |
|------|------------|------|
| **录制配音** | `V` | 从播放头开始，边看视频边录旁白（视频会同步播放） |
| **导入音频文件** | `M`（添加音频） | 导入提前录好的配音 MP3、背景乐等 |

加上音频轨道后，选中它可调：

| 设置 | 作用 |
|------|------|
| 音量 | 调大/调小 |
| 淡入 / 淡出 | 平滑进出 |
| 循环 | 背景乐循环播放 |
| 静音 | 临时静音 |

> 这样就能实现「画面是录屏 + 声音是后期配音/配乐」的组合。整体音量在「音频」面板统一调。

---

## 三、给演示视频的组合建议

| 场景 | 推荐做法 |
|------|----------|
| 现场讲解型演示 | 录制时开麦克风直接讲 + 开字幕（字幕兜底，方便静音观看） |
| 精修型演示 | 先录纯操作，后期用 `V` 录配音 / `M` 导入音频 + 开字幕 |
| 需要配乐的演示 | 录屏 + 音频轨道加背景乐（音量调低，别盖过人声） |

---

## 四、相关提醒

- 生成转录前，确认录制里**确实有可识别的语音**；纯操作无讲解的视频，转录会是空的。
- 识别质量受**口音、语速、环境噪音**影响，个别字句在转录面板双击改正即可。
- 配音/配乐与源音频的音量平衡，用「音频」面板的**输出电平**和音频轨道的**音量**来调。
- 转录是很多功能的地基：改字、剪静音、字幕、AI 编辑都建立在它上面。录完先转录，事半功倍。
