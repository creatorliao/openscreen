# 02 · 操作教程：从启动录制到导出视频

> 这一篇是「手把手」版，带你走完一条完整路径：**启动 → 选源 → 录制 → 停止进编辑器 → 编辑 → 导出**。
> 建议跟着实际操作一遍，遇到没见过的按钮就回来对照。

---

## 〇、开始前须知（平台差异）

| 平台 | 注意点 |
|------|--------|
| **Windows** | 需 Windows 10 Build 18362+（推荐 11）。首次使用按系统提示授权「屏幕录制」。系统音频开箱即用。 |
| **macOS** | 需 macOS 13（Ventura）+。首次使用会要求 **屏幕录制** 和 **辅助功能** 两项权限（系统会引导你去设置页，开启后重开应用）。macOS 15+ 会定期再次询问屏幕录制权限，那是系统行为，再次允许即可。 |
| **Linux** | 原生采集和系统音频需要 `xdg-desktop-portal` + PipeWire；没有时自动回退浏览器采集管线，能力略少。系统声音通常需要 PipeWire。 |

> 通用：内存 8 GB 起步、16 GB 推荐。三端编辑器与导出能力一致。

首次使用若提示授权，按提示去系统设置开启即可。

---

## 一、启动应用

打开 OpenScreen。你会看到一个悬浮的 **HUD 控制条**（一个可拖动的小面板，可横排/竖排），这是录制的主入口。

HUD 上的主要控件（从左到右大致为）：

- **来源（Source）**：显示当前选的录制源（屏幕/窗口），点它打开源选择器
- **系统音频**：录软件本身的声音
- **麦克风**：录你的讲解声
- **摄像头**：开关摄像头
- **光标**：在「可编辑光标」和「系统光标」间切换
- **录制**（红色圆点）：开始/停止
- **打开工作室**（Open Studio）：打开编辑器
- **笔记**（Notes）：打开提词笔记窗口（可自动滚动）
- **语言 / 隐藏 / 关闭**

> 录制按钮在**选好源之前是禁用的**（悬停提示「请选择要录制的源」）。

---

## 二、选择录制源（录什么）

点 HUD 上的「**来源**」按钮，打开源选择器：

- **屏幕（Screens）**：录制整个显示器。
- **窗口（Windows）**：只录某一个应用窗口。**好处**：成片干净，不会录到桌面弹窗等其他内容；**注意**：只能录「可见（非最小化）」的窗口。

> 演示视频建议：**优先选「窗口」**，把你要讲的软件单独框出来。

选中缩略图后确认（**共享/Share**），HUD 上的来源标签会变成你选中的源名。

---

## 三、配置录制选项

在正式开始前，把这几项按需设好：

| 选项 | 作用 | 演示视频建议 |
|------|------|-----------|
| **系统音频** | 录软件本身的声音 | 视内容需要，一般**开** |
| **麦克风** | 录你的讲解声 | 讲操作时**开** |
| **摄像头** | 录一份摄像头旁路，成片用「摄像头布局」决定是否叠加 | 要露脸时**开** |
| **光标** | 可编辑光标（默认，记轨迹供后期润色）/ 系统光标（直接烧进画面） | 保持默认「可编辑光标」 |

> 麦克风在**录制过程中无法切换**，所以开始前先确认好开关；摄像头同理。

---

## 四、开始录制

1. 选好源后，点「**录制**」按钮。
2. 会先显示 **3-2-1 倒计时**，结束后正式开录。
3. 录制开始后，录制按钮变成**红色计时**（显示录制时长）。

然后你就可以**正常去操作你的软件、正常讲话**了。

---

## 五、录制中的控制

录制中 HUD 会出现这几个辅助按钮：

| 按钮 | 作用 |
|------|------|
| **暂停 / 继续** | 临时停一下，再按继续（适合中途去处理事情） |
| **重新开始** | 放弃当前这次，重录 |
| **取消（X）** | 放弃这次录制 |
| **停止**（点红色录制按钮） | 结束录制，进入编辑器 |
| **隐藏（−）** | 把控制条从眼前收起来，不挡操作（只是暂时看不见，不影响录制） |

> 需要边录边看讲稿？点 HUD 的「**笔记**」打开提词窗，支持自动滚动。

---

## 六、停止录制 → 进入编辑器

点「**停止**」后，OpenScreen 会保存录制并**自动进入编辑器**。

编辑器顶部有**三个模式**：

| 模式 | 作用 |
|------|------|
| **媒体（Media）** | 素材库：查看、搜索、导入录制/视频/音频/图片，管理转录 |
| **编辑（Edit）** | 时间线编辑主界面（预览 + 时间线 + 右侧属性面板 + 转录/字幕/聊天面板） |
| **录制（Rec）** | 配好源后开一次新录制（回到 HUD 开录） |

日常剪辑待在「编辑」模式。你会看到：

- **中间**：预览画面
- **下方**：时间线（片段 + 各类区域）
- **右侧**：属性检查器（随选中对象变化）
- **左侧/侧栏**：转录（Transcript）、字幕（Captions）、聊天（AI）面板

---

## 七、编辑（核心操作速览）

### 7.1 时间线区域类型

在时间线上，你可以添加这些「区域」：

| 区域 | 快捷键 | 作用 |
|------|--------|------|
| 缩放 | **Z** | 放大某个区域（重点强调） |
| 剪辑 | **T** | 标记要删掉的片段（红色区域导出时被剪掉） |
| 变速 | **S** | 快进 / 慢放某段 |
| 标注 | **A** | 加文本 / 箭头 / 图片 / 模糊 |
| 全屏摄像头 | **C** | 摄像头占满整屏，结束平滑还原 |
| 添加音频 | **M** | 加一段配音 / 背景乐图层 |
| 录制配音 | **V** | 从播放头开始录旁白 |

> 删除选中的区域：`Ctrl/Cmd + D`。片段可拖动重排，双击片段可编辑入点/出点。

### 7.2 右侧属性面板能干什么（按选中的对象变化）

- **背景（Background）**：壁纸 / 纯色 / 渐变 / 自定义图片
- **画面合成（Composition/Effects）**：阴影、圆角、内边距、运动模糊、宽高比适配
- **光标（Cursor）**：样式、大小、平滑、运动模糊、点击弹跳
- **摄像头布局（Camera layout）**：画中画 / 垂直堆叠 / 双画框、形状、镜像、背景
- **缩放（Zoom）**：缩放级别、焦点位置、对焦模式（自动/手动）、3D 旋转
- **音频（Audio）**：整体输出电平
- **裁剪（Crop）**：裁掉多余部分、重设宽高比

> 新手第一步：先把**该剪掉的片段**用「剪辑」（T）标出来，成片立刻干净很多。

### 7.3 转录 / 字幕 / AI（详见 03、04 篇）

- **转录面板**：本地 Whisper 转录，双击改字、退格删词（画面同步剪掉）
- **字幕面板**：开「显示字幕」，字幕实时来自转录，可调样式、翻译
- **聊天面板**：连接大模型提供方后，用自然语言让代理帮你剪片、加字幕（默认关闭）

### 7.4 随时保存 / 打开项目

编辑过程中可随时把工作**保存为 `.openscreen` 项目文件**，下次打开继续改：

| 操作 | 入口 |
|------|------|
| **保存项目** | 顶部保存按钮，或 `Ctrl/Cmd + S` |
| **打开项目** | 顶部「打开项目」，或 `Ctrl/Cmd + O` |
| **新建项目** | 顶部「新建项目」 |

> 打开项目也支持直接把 `.openscreen` 文件拖进编辑器窗口。

---

## 八、导出视频

1. 在编辑器顶部点「**导出**」，打开导出面板。
2. 选择格式：
   - **MP4 视频**：常规视频（演示课件用这个）
   - **GIF 动画**：轻量分享、循环播放
3. 按需调参数：

| 参数 | 说明 |
|------|------|
| 分辨率 | **720p / 1080p / 源画质（Source）**，默认 1080p |
| 帧率 | 输出帧率 |
| 编码格式 | 兼容性优先 / 可能更高压缩比 |
| GIF 帧率 | GIF 可调帧率 |
| 循环 | GIF 是否循环播放 |
| GIF 尺寸 | 中 / 大 / 原始 |

4. 点「**导出 MP4**」（或「导出 GIF」）。
5. 等待渲染完成（GPU 硬件编码；没有兼容 GPU 时会提示改用 CPU，耗时更长）。
6. 完成后点「**在文件夹中显示**」定位成品。

---

## 九、完整路径回顾（速记版）

```
启动（HUD）→ 选「窗口/屏幕」→ 共享
     → 开麦克风/系统音频（+摄像头/光标）
     → 点「录制」→ 3-2-1 倒计时 → 边操作边讲解
     → 暂停/继续 / 重新开始 / 取消（按需）
     → 点「停止」→ 自动进编辑器
     → 剪辑(T)/缩放(Z)/变速(S)/标注(A)/音频(M)/配音(V)/字幕/背景
     → 导出 MP4 → 在文件夹中显示
```

## 十、默认快捷键速查表

| 操作 | 默认快捷键 |
|------|-----------|
| 添加缩放 | `Z` |
| 添加剪辑 | `T` |
| 添加变速 | `S` |
| 添加标注 | `A` |
| 添加全屏摄像头 | `C` |
| 添加音频 | `M` |
| 录制配音 | `V` |
| 删除选中 | `Ctrl/Cmd + D` |
| 播放 / 暂停 | `空格` |
| 复制属性 | `Ctrl/Cmd + C` |
| 粘贴属性 | `Ctrl/Cmd + V` |
| 撤销 | `Ctrl/Cmd + Z` |
| 重做 | `Ctrl/Cmd + Shift + Z`（或 `Ctrl/Cmd + Y`） |
| 循环切换标注 | `Tab` / `Shift + Tab` |
| 平移时间线 | `Shift + 滚轮` |
| 缩放时间线 | `Ctrl/Cmd + 滚轮` |
| 上一帧 / 下一帧 | `←` / `→` |
| 打开应用（HUD） | `Ctrl/Cmd + Shift + O` |

> 快捷键可在编辑器里**自定义**（「快捷键」设置 → 自定义；固定项不可改）。
